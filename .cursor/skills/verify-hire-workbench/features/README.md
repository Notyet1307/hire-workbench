# 功能地图

这里记录用户路径及证明方式。命令与隔离规则由上级 `SKILL.md` 统一维护。

| 路径 | 要证明的结果 | 文件 |
|---|---|---|
| 岗位与标准 | 创建、编辑后持久化，版本更新 | [jobs.md](jobs.md) |
| 候选人与简历 | 文本与文件导入可用；缺正文可识别 | [resumes.md](resumes.md) |
| 分析与证据 | 异步任务、原文引用、版本和失败状态可信 | [analysis.md](analysis.md) |
| 复核与面试 | 人工决定与面试记录保存且反映到界面 | [review.md](review.md) |
| 重启、访问与导出 | 数据保留，访问约束与导出边界正确 | [workspace.md](workspace.md) |

`npm run e2e` 是默认完整浏览器入口。当前 `tests/e2e/workflow.spec.ts` 只有两条用例：`岗位、简历、证据定位、复核与面试的完整浏览器路径`，以及 `简历文件上传与移动宽度布局`。

第一条使用界面创建岗位、手工填写简历、关联、分析、点击证据、复核、面试与刷新，并通过公开 API 核查副作用。第二条使用界面上传 TXT 并检查 390 像素宽度布局。岗位编辑、历史快照、PDF/DOCX 解析、任务重试、重启和访问边界等由服务端测试补充。地图列出的是功能和验证方法，具体执行结果以报告为准。
