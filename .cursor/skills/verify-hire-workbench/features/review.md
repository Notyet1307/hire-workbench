# 人工复核与面试

## Sub-features

- 记录复核人、推进决定与说明。
- 将应聘阶段更新为面试、待复核或不推进。
- 安排面试并保存备注和结果。

## How to get to it (user POV)

打开候选人的分析后，填写“复核人”“复核结论”和“判断与下一步”，点击“保存复核”。点击“安排面试”填写时间、面试官和地点，再进入“面试管理”点击“填写记录”。

## Driving it with Playwright

执行 `npm run e2e -- --grep '完整浏览器路径'`。当前用例选择 `getByLabel('复核结论')` 的 `advance`，在 `getByLabel('复核说明')` 填写说明后“保存复核”。

随后用“面试时间”“面试官”“地点或会议链接”填写安排；从主导航“面试管理”进入“填写记录”，填写“面试记录”，把“面试结论”设为 `pass` 并“保存面试”。页面刷新后文字仍可见；公开 API 回读确认复核数量、面试结果和应聘阶段，保存 `03-interview.png`。

页面显示“判断与下一步”，其测试可访问名称是 `复核说明`，二者不要混淆。当前浏览器只走推进面试分支，暂缓和不推进不记为浏览器已覆盖。

## Gotchas

分析完成不自动录用或拒绝。界面当前选中值不代表写入成功。单工作区中的“复核人”是业务记录字段，不是经过企业身份认证的登录主体，不能据此声称已有多人权限体系。
