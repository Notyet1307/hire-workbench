# 工作区、访问与留档

## Sub-features

- 本地数据在重启后保留。
- 访问口令和跨来源写入边界生效。
- 导出分析快照及工作区业务数据。
- 查看重要操作记录。

## How to get to it (user POV)

打开工作台；配置口令时在“工作区访问令牌”填入凭据并点击“进入工作区”。在分析报告中用“导出当前分析报告”链接下载单份结果，在“工作区设置”用“导出工作区 JSON”留档。

## Driving it with Playwright

完整浏览器验收使用 `npm run e2e`。第一条用例刷新面试页面并通过公开 API 回读记录，还用 HTTP 请求下载分析 JSON 并检查复核记录；没有点击下载按钮或操作登录页面。第二条用例在 390 × 844 视口下检查工作台标题及横向溢出，保存 `05-mobile.png`。

`tests/api.test.ts` 的 `SQLite 文件重启后保留数据，运行中任务被标记失败并可重试` 检查关闭并重新创建数据库实例后的数据与任务恢复；`远程访问需要口令；登录Cookie和跨域写入边界有效` 检查访问边界；`业务导出包含历史资料但不包含访问凭据` 检查导出。数据库实例重建不等同于完成用户目标机器的进程与系统重启演练。

若需要完整服务进程重启验收，对手动实例先运行 `npm run doctor`，使用独立数据目录创建记录，退出该进程，再用同一目录启动并核查内容。将这次操作独立记录，不能把已有 API 测试结果重复用作证据。

## Gotchas

仅刷新页面不能证明进程重启后持久化。JSON 导出不是完整数据库备份，也没有自动导入恢复。口令不是 RBAC。导出不得包含环境变量、模型密钥和访问口令；证据只用合成数据。
